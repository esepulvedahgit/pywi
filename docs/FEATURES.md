# Funcionalidades de PyWI / PyWI Features

> Guía completa de funcionalidades para el usuario final.
> Complete feature guide for end users.

---

## Editor de código / Code Editor

**ES:** PyWI incluye un editor de código Python completo basado en CodeMirror 6, con resaltado de sintaxis, numeración de líneas y guardado automático.

**EN:** PyWI includes a full Python code editor based on CodeMirror 6, with syntax highlighting, line numbers, and auto-save.

- Resaltado de sintaxis Python / Python syntax highlighting
- Guardado automático cada segundo / Auto-save every second
- Indentación configurable: 2 o 4 espacios / Configurable indentation: 2 or 4 spaces
- Temas: light (claro), vibrant-dark, midnight-obsidian

### Barra de teclas especiales (móvil) / Special Keys Bar (mobile)

En dispositivos móviles, una barra de teclas inserta los caracteres más usados en Python que son difíciles de escribir en teclados táctiles:

`Tab` `:` `=` `_` `[` `]` `{` `}` `(` `)` `"` `'` `,` `.` `/` `+` `-` `*` `#`

On mobile, a special keys bar inserts the most common Python characters that are hard to type on touch keyboards.

## Ejecución de código / Code Execution

**ES:** Ejecuta scripts Python directamente desde el navegador en una terminal interactiva real (xterm.js) conectada por WebSocket a un proceso PTY en el servidor — no es un simple streaming de texto, es una terminal de verdad.

**EN:** Run Python scripts directly from the browser in a real interactive terminal (xterm.js) connected via WebSocket to a PTY process on the server — not plain text streaming, an actual terminal.

- Salida stdout/stderr en vivo, carácter a carácter / Live stdout/stderr output, character by character
- Soporta `input()` interactivo durante la ejecución / Supports interactive `input()` during execution
- Timeout de ejecución configurable (defecto 180s) / Configurable execution timeout (default 180s)
- Muestra duración y código de salida / Shows duration and exit code
- Errores de Python con traceback formateado (colores ANSI) / Python errors with formatted traceback (ANSI colors)
- Botón **Run** en el header (también funciona en móvil) / **Run** button in the header (also works on mobile)

## Gráficos matplotlib / Matplotlib Charts

**ES:** Los gráficos generados con `plt.savefig()` se muestran automáticamente en la pestaña **Plots** de la consola al terminar la ejecución.

**EN:** Charts generated with `plt.savefig()` are automatically displayed in the **Plots** tab of the console after execution.

```python
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 10, 100)
plt.plot(x, np.sin(x))
plt.title('Seno / Sine')
plt.savefig('grafico.png')  # ← se muestra automáticamente / auto-displayed
```

- Soporta PNG, JPG, SVG, GIF
- Descarga individual de cada gráfico / Individual chart download
- Compatible con matplotlib, seaborn, pandas `.plot()`

## Visor de datasets / Dataset Viewer

**ES:** Previsualiza archivos de datos directamente en la interfaz sin necesidad de ejecutar código.

**EN:** Preview data files directly in the interface without running code.

**Formatos soportados / Supported formats:** CSV, TSV, Excel (.xlsx/.xls), Parquet, JSON

Al hacer click en un dataset del Sidebar se abre el visor con:
Clicking a dataset in the Sidebar opens the viewer with:

- **Datos / Data tab**: tabla con scroll horizontal, índice de filas, tipo de dato por columna con badge de color
- **Estadísticas / Stats tab**: resultado de `df.describe()` con count, mean, std, min, max, percentiles
- Badge con dimensiones: `N filas × M columnas` / dimensions badge: `N rows × M columns`

El botón 📋 copia la ruta del archivo para usarla en el script:
The 📋 button copies the file path for use in scripts:
```python
import pandas as pd
df = pd.read_csv('mis_datos.csv')
```

### Vista previa de archivos de salida / Output File Preview

**ES:** Los archivos generados por tu script durante la ejecución (además de los gráficos) aparecen en una sección de almacenamiento y pueden previsualizarse sin descargarlos.

**EN:** Files generated by your script during execution (besides charts) appear in a storage section and can be previewed without downloading them.

- Previsualización en el navegador para tipos soportados; si el archivo es muy grande, cae automáticamente a descarga directa / In-browser preview for supported types; falls back to direct download for very large files

## Gestor de paquetes / Package Manager

**ES:** Instala, actualiza y elimina paquetes Python del entorno virtual directamente desde la interfaz.

**EN:** Install, update, and remove Python packages from the virtual environment directly from the interface.

- Busca e instala cualquier paquete de PyPI / Search and install any PyPI package
- Lista de paquetes instalados con versiones / Installed packages list with versions
- Notificación de paquetes desactualizados / Outdated packages notification
- Actualización individual o masiva / Individual or bulk update
- Paquetes base preinstalados: `numpy`, `pandas`, `matplotlib`, `seaborn`, `scikit-learn`, `openpyxl`, `xlrd`, `pyarrow`
- Habilitar la librería `os` con consentimiento explícito: por defecto el sandbox bloquea `import os`; el usuario puede activarla desde el gestor de paquetes, quedando limitada a un helper seguro (`getcwd`, `listdir` restringido al proyecto, `clear`, `get_secret`) en vez de acceso irrestricto al sistema de archivos / Enable the `os` library with explicit consent: by default the sandbox blocks `import os`; the user can enable it from the package manager, restricted to a safe helper (`getcwd`, project-jailed `listdir`, `clear`, `get_secret`) instead of unrestricted filesystem access

## Tutor IA / AI Tutor

**ES:** Asistente de chat integrado que ayuda a entender código, explicar errores y sugerir mejoras. Soporta múltiples proveedores de IA.

**EN:** Integrated chat assistant that helps understand code, explain errors, and suggest improvements. Supports multiple AI providers.

**Proveedores soportados / Supported providers:**
- OpenAI (GPT-4o, GPT-4o-mini, etc.)
- DeepSeek (deepseek-chat, deepseek-coder)
- Google Gemini (gemini-1.5-flash, gemini-1.5-pro)
- Custom: cualquier API compatible con OpenAI / any OpenAI-compatible API

**Acciones rápidas / Quick actions:**
- 💬 **Explicar error** — analiza el traceback actual / analyze current traceback
- 📖 **Explicar código** — explica el código del editor / explain editor code
- ✨ **Sugerir mejora** — propone optimizaciones / suggest improvements

**Panel flotante (desktop) / Floating panel (desktop):**
- En pantallas ≥768px el tutor se convierte en una ventana flotante: arrastrable por el header, redimensionable desde bordes/esquinas, con maximizar/restaurar / On screens ≥768px the tutor becomes a floating window: draggable by the header, resizable from edges/corners, with maximize/restore
- Posición y tamaño se guardan por usuario en localStorage / Position and size are saved per user in localStorage
- En móvil se mantiene como bottom-sheet / On mobile it stays as a bottom-sheet

**Respuestas en streaming / Streaming responses:**
- El texto aparece a medida que el modelo responde, con botón para detener la generación / Text appears as the model responds, with a button to stop generation
- Sugerencias de código se muestran como diff contra el editor / Code suggestions are shown as a diff against the editor
- El tutor tiene contexto del archivo abierto en el IDE / The tutor has context of the file currently open in the IDE

**Monitor de tokens y costo / Token & cost monitor:**
- Cada respuesta muestra tokens de entrada/salida y costo estimado según el proveedor / Each response shows input/output tokens and estimated cost based on the provider

Las API keys se almacenan cifradas (AES-256-GCM) en el servidor.
API keys are stored encrypted (AES-256-GCM) on the server.

## Gestión de proyectos y archivos / Project & File Management

- Crea múltiples proyectos / Create multiple projects
- Organiza scripts en carpetas / Organize scripts in folders
- Mueve archivos entre carpetas / Move files between folders
- Sube datasets hasta 30 MB / Upload datasets up to 30 MB
- Renombra y elimina archivos y carpetas / Rename and delete files and folders

**Formatos de dataset soportados:** `.csv` `.txt` `.xlsx` `.xls` `.json` `.parquet` `.log`

### Copia de seguridad y restauración / Backup & Restore

**ES:** Desde Configuración → Copia de seguridad puedes descargar un `.zip` cifrado con AES-256 que incluye todos tus scripts, salidas, datasets y documentos.

**EN:** From Settings → Backup you can download an AES-256 encrypted `.zip` containing all your scripts, outputs, datasets, and documents.

- Requiere una contraseña de al menos 12 caracteres ASCII (sin acentos ni ñ) que se usa para cifrar el archivo / Requires a password of at least 12 ASCII characters (no accents) used to encrypt the file
- Esa misma contraseña es necesaria para restaurar la copia — guárdala en un lugar seguro / That same password is required to restore the backup — keep it somewhere safe
- **Restaurar:** sube el `.zip` y su contraseña desde Configuración → Copia de seguridad. ⚠️ La restauración **reemplaza** todos los proyectos, archivos y documentos actuales; la acción no se puede deshacer / **Restore:** upload the `.zip` and its password from Settings → Backup. ⚠️ Restoring **replaces** all current projects, files, and documents; this action cannot be undone

## Panel de rendimiento / Performance Panel

**ES:** Panel en tiempo real en la barra lateral mostrando el uso de recursos del contenedor.

**EN:** Real-time panel in the sidebar showing container resource usage.

| Métrica | Descripción / Description |
|---|---|
| **RAM** | Memoria usada / total del contenedor / Container used/total memory |
| **CPU** | Porcentaje de uso de CPU / CPU usage percentage |
| **GPU** (amd64) | Uso de GPU NVIDIA en % + memoria usada/total / NVIDIA GPU usage % + used/total memory |
| **NPU** (arm64) | Uso de NPU RK3588S en % + carga por núcleo (C0/C1/C2) / RK3588S NPU usage % + per-core load |

El panel se actualiza cada 5 segundos. Si el acelerador no está disponible, aparece en gris.
The panel updates every 5 seconds. If the accelerator is unavailable, it appears grayed out.

## Bloqueo por inactividad / Inactivity Lock

**ES:** Tras 10 minutos sin actividad (sin mover el mouse, tocar la pantalla ni usar el teclado) la sesión se bloquea automáticamente.

**EN:** After 10 minutes of inactivity (no mouse movement, touch, or keyboard input) the session locks automatically.

- Una pantalla de bloqueo cubre el IDE y pide la contraseña para continuar / A lock screen covers the IDE and asks for the password to continue
- El estado del editor y la consola se conserva — no se pierde trabajo al desbloquear / Editor and console state is preserved — no work is lost on unlock
